# Project 4: Find Movie Tags

This MapReduce program extracts and processes tags associated with movies using the MovieLens dataset.

## Files
- `MovieTags.java`: The MapReduce code to process tags.
- `ml-latest-small/`: The directory containing the MovieLens dataset (including `tags.csv`).

## Step-by-Step Execution (From Scratch)

Follow these steps if you are running this project for the very first time. Open your terminal and navigate to the `Code/4` directory before starting.

### 1. Compile the Java Code
First, compile the MapReduce program and package it into a JAR file:
```bash
export HADOOP_CLASSPATH=$(hadoop classpath)
javac -classpath ${HADOOP_CLASSPATH} -d . MovieTags.java
jar -cvf MovieTags.jar *.class
```

### 2. Start Hadoop Services
Start your Hadoop cluster (HDFS and YARN):
```bash
start-all.sh
```

### 3. Prepare Data in HDFS
Create a directory in the Hadoop Distributed File System (HDFS) and upload the dataset:
```bash
# Create the input directory in HDFS
hdfs dfs -mkdir -p /movielens

# Upload tags.csv from your local machine to HDFS
hdfs dfs -put ml-latest-small/tags.csv /movielens/tags.csv
```
*(Note: If you run this step multiple times, you might get a "File exists" warning, which is perfectly fine).*

### 4. Run the MapReduce Job
Hadoop requires the output folder to NOT exist before the job starts. Remove it if necessary, then run the job:
```bash
# Delete the old output directory (if it exists)
hdfs dfs -rm -r /output_tags

# Run the map-reduce job
hadoop jar MovieTags.jar MovieTags /movielens/tags.csv /output_tags
```

### 5. View the Results
Check the processed output generated by the MapReduce job:
```bash
hdfs dfs -cat /output_tags/part-r-00000
```

*(When you are completely finished testing, you can stop your Hadoop services using `stop-all.sh`).*
