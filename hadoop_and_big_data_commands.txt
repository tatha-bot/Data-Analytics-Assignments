# Basic Hadoop HDFS Commands
1. Start HDFS: `start-dfs.sh`
2. Start YARN: `start-yarn.sh`
3. List files in root directory: `hdfs dfs -ls /`
4. Create a directory: `hdfs dfs -mkdir /my_directory`
5. Upload a file to HDFS: `hdfs dfs -put local_file.txt /my_directory/`
6. Download a file from HDFS: `hdfs dfs -get /my_directory/local_file.txt /local/path/`
7. Read file content: `hdfs dfs -cat /my_directory/local_file.txt`
8. Delete a file: `hdfs dfs -rm /my_directory/local_file.txt`
9. Delete a directory: `hdfs dfs -rm -r /my_directory`
10. Check HDFS status: `hdfs dfsadmin -report`

# Commands and Snippets for Required Programs

1. Install Hadoop and perform HDFS tasks
- Install: (Typically download tar.gz, extract, configure core-site.xml, hdfs-site.xml, format namenode: `hdfs namenode -format`)
- Add file: `hdfs dfs -put local.txt /hdfs/dir/`
- Retrieve: `hdfs dfs -get /hdfs/dir/local.txt ./`
- Delete: `hdfs dfs -rm /hdfs/dir/local.txt`

2. Word Count MapReduce
- Run jar: `hadoop jar wordcount.jar WordCount /input_dir /output_dir`
- View output: `hdfs dfs -cat /output_dir/part-r-00000`

3. Matrix Multiplication with Hadoop MapReduce
- Run jar: `hadoop jar matrix.jar MatrixMultiplication /input_dir /output_dir`

4. Find tags associated with each movie (Movie Lens)
- Run jar: `hadoop jar movietags.jar MovieTags /movielens/tags.csv /output_tags`

5. Sort and aggregate data using HiveQL
- Enter Hive: `hive`
- Query: `SELECT category, COUNT(*), SUM(price) FROM products GROUP BY category ORDER BY category;`

6. Java application for max temperature using Spark
- Submit spark job: `spark-submit --class MaxTemperature --master local[2] max-temp.jar /input_data.csv`

7. Import/Export data from various databases (Sqoop is commonly used)
- Import to HDFS: `sqoop import --connect jdbc:mysql://localhost/db --username root --password pass --table employees --target-dir /sqoop/employees`
- Export to MySQL: `sqoop export --connect jdbc:mysql://localhost/db --username root --password pass --table employees --export-dir /sqoop/employees`

8. Install and execute NoSQL commands (MongoDB)
- Start mongo shell: `mongo`
- Show dbs: `show dbs`
- Use db: `use myDB`
- Insert: `db.collection.insert({name: "test"})`

9. MongoDB Functions (count, sort, limit, skip, aggregate)
- Count: `db.collection.countDocuments({ status: "A" })`
- Sort: `db.collection.find().sort({ age: -1 })`
- Limit: `db.collection.find().limit(5)`
- Skip: `db.collection.find().skip(10)`
- Aggregate: `db.collection.aggregate([ { $group: { _id: "$category", total: { $sum: 1 } } } ])`

10. Store big data in HBase / MongoDB / Pig
- Pig store example: `STORE processed_data INTO '/output/dir' USING PigStorage(',');`
- HBase shell: `hbase shell`, `put 'mytable', 'row1', 'cf:col1', 'value'`

11. Implement clustering techniques using SPARK
- Submit PySpark script: `spark-submit kmeans_clustering.py`

12. Streaming data analysis (Flume, PySpark)
- Start Flume agent: `flume-ng agent -n a1 -c conf -f flume_twitter.conf -Dflume.root.logger=INFO,console`
- Run PySpark streaming: `spark-submit twitter_stream.py`

13. Bayes' Theorem two-class classification (Iris)
- Python execution: `python naive_bayes_iris.py`

14. Naive Bayes Classifier on text (SMS spam)
- Python execution: `python spam_detector.py`

15. Compare Gaussian and Bernoulli Naive Bayes on image dataset
- Python execution: `python compare_nb_images.py`

16. Bayes' Theorem multi-class classification (Image dataset)
- Python execution: `python multiclass_nb.py`

17. Histograms density estimation on 1D and 2D data
- Python execution: `python histogram_density.py`

18. Maximum Likelihood Estimation for image dataset
- Python execution: `python mle_images.py`

19. Parzen Window method for non-parametric density estimation
- Python execution: `python parzen_window.py`

20. Agglomerative and Hierarchical Clustering and dendrogram plotting
- Python execution: `python hierarchical_clustering.py`

21. K-Nearest Neighbor algorithm for handwritten image dataset (MNIST)
- Python execution: `python knn_mnist.py`

22. Principal Component Analysis (PCA) on high-dimensional data (Iris)
- Python execution: `python pca_iris.py`

23. Integrated Component Analysis (ICA) to isolate singing voice
